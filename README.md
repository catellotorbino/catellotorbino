# Catello Torbino — MT Group

Sviluppo e gestisco prodotti software per l'e-commerce e il retail: negozi online a canone e gestionali sincronizzati.

## Prodotti

**Besell** — Piattaforma e-commerce multi-tenant (Next.js 15) a canone fisso.
Negozi online pronti all'uso con catalogo sincronizzato automaticamente dal gestionale: categorie, prodotti, schede tecniche e immagini. Multi-negozio su un'unica installazione, ogni cliente con il suo dominio e il suo brand.

**SellerManager** — Gestionale per rivenditori.
Listini fornitori, gestione catalogo e schede tecniche, sincronizzazione automatica verso i negozi e-commerce collegati.

## Stack tecnologico

Next.js 15 (App Router) - TypeScript - Node.js - SQLite - GitHub Actions CI/CD - Nginx - Server dedicati Kamatera
